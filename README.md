# Bessy od Podhradského rybníka

Statická kopie webu chovatelské stanice. Astro servíruje osm stránek, styly jsou z původního Webnode webu a fotky leží v `public/photos`.

Původní nezmenšené snímky jsou ve složce `originals/` a do gitu ani na hosting nejdou.

```bash
npm install
npm run dev
```

Stránky: `/`, `/o-nas/`, `/sluzby/`, `/nase-prace/`, `/fotogalerie/`, `/cenik/`, `/kontakt/`, `/vrh-a/`.
